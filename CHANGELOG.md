# Changelog

## 1.0.0

The first public release.

- **Paltop terminal**: btop-style dashboard with server and host health,
  players, backups, trends, base camps, every player's Pals with the team
  builder, passive planner and breeding helper, the crash log with an
  automatic investigation, and an admin menu.
- **Paltop web**: the page for the players, with logins linked to each
  player's character, Pals, team builder with wishes and side-by-side
  comparison, boss planner, Palpedia, traitpedia, Pal battles (automatic and
  fought by hand, with chiptune music and sounds), achievements, the quest
  list, and a chat between the page and the game.
- `install.sh` installs either part or both, and the release has an archive
  for each.
